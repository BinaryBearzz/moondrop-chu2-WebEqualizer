# Chu Studio Web

เว็บ EQ สำหรับ Moondrop CHU 2 DSP ใช้ WebHID เชื่อมต่ออุปกรณ์จากเบราว์เซอร์โดยตรง ไม่ต้องติดตั้งไลบรารี JavaScript หรือเซิร์ฟเวอร์ backend

## เริ่มใช้งาน

ต้องใช้ Chrome หรือ Edge ที่รองรับ WebHID และเปิดผ่าน secure context (`https://` หรือ `localhost`)

```bash
npm start
```

จากนั้นเปิด <http://localhost:4173> กด **เชื่อมต่ออุปกรณ์** เลือก CHU 2 แล้วปรับแบนด์ตามต้องการ การเปลี่ยนแปลงจะทดลองเสียงกับอุปกรณ์ทันที แต่ยังไม่บันทึกถาวรจนกดยืนยัน **บันทึกลงในอุปกรณ์** โดยเว็บจะอ่านค่ากลับมาตรวจสอบก่อนสั่งบันทึก

เมื่อเชื่อมต่อและอ่านค่าอุปกรณ์แล้ว การแก้แบนด์จะส่งไปทดลองเสียงกับ DSP แบบ live โดยหน่วงสั้น ๆ เพื่อรวมการลากสไลเดอร์ให้ลื่น ค่า preview ยังไม่ถูก commit จึงไม่ใช่การบันทึกถาวร ปุ่ม **คืนค่า EQ ที่อ่านล่าสุด** ใช้ยกเลิกการทดลอง และการตัดการเชื่อมต่อที่มี preview ค้างจะถามก่อนคืนค่าเดิม

บันทึกโปรไฟล์ตั้งชื่อไว้ใน local storage ของเบราว์เซอร์ได้ และใช้ **นำเข้า / ส่งออก JSON** เพื่อคัดลอกไปคลิปบอร์ด ดาวน์โหลดไฟล์ หรือวางข้อความ/เลือกไฟล์ JSON เพื่อนำเข้า โปรไฟล์ JSON มีเวอร์ชันและตรวจสอบชนิดฟิลเตอร์กับช่วงค่าทั้งห้าแบนด์ก่อนนำไปใช้ การโหลดหรือนำเข้าโปรไฟล์จะเริ่ม live preview เมื่อเชื่อมต่ออยู่ แต่ยังไม่บันทึกถาวรจนกดยืนยันแยกต่างหาก

การบันทึกจะทำให้ DSP รีสตาร์ตชั่วครู่ เบราว์เซอร์และระบบปฏิบัติการเป็นผู้กำหนดว่า WebHID เข้าถึง HID control interface ของอุปกรณ์ได้หรือไม่ โดยเฉพาะบน Windows ซึ่งการเข้าถึงอาจถูกจำกัดโดย HID driver

## ทดสอบ

```bash
npm test
```
